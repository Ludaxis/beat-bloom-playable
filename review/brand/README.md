# Ludaxis Studio assets

Studio colors, typography and mark come from the existing ludaxis.io project:

- `src/app/globals.css` and `docs/design-system.md`: dark ink surfaces, mint/coral accents, semantic color tokens and compact controls.
- `src/components/site/markGeometry.ts`: approved eight-ray mark and coral pivot, preserved in `ludaxis-mark.svg`.
- `src/lib/fonts.ts`: Inter for body/UI labels and Comfortaa for headings/actions. Latin WOFF2 files are the website's existing self-hosted font builds. Their SIL Open Font Licenses are included here.

These styles apply only to Studio. Gameplay and ending artwork keep Beat Bloom's own branding.
